# New Features Feed

This folder is a lightweight feed of product/CLI changes for agents (for example Clio, Wren) to read and stay current.

## How to use

- Add one Markdown file per change using: `YYYY-MM-DD-short-title.md`
- Keep entries short and factual.
- Include:
  - `Summary`
  - `Why it matters`
  - `How to use`
  - `Files touched`
  - `Validation`
  - `Commit`
- Add the new file to [`INDEX.md`](./INDEX.md) at the top.

## Audience

- Human maintainers
- OpenClaw sibling agents that need current project context

## Notes

- This feed is intentionally concise and operational.
- It complements `CHANGELOG.md` (release-level) with implementation-level updates.
